# NQ Strategy Lab

Interactive NQ/MNQ strategy research dashboard for testing liquidity-reversal assumptions, risk settings, and execution rules.

## Deploy to Vercel

Import this repository in Vercel. The framework preset should be detected as **Next.js**; no environment variables are required.

## Local development

```bash
npm install
npm run dev
```

The included results use synthetic demonstration data. Connect validated historical minute data before making trading decisions.
